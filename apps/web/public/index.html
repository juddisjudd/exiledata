ExileData

ExileData is a developer data platform for Path of Exile 1 and Path of Exile 2 tooling: a versioned, normalized dataset with a gated API and SDKs, so PoE tool developers don't need to embed large JSON datasets or reimplement data extraction and normalization.

This site and the platform are under early development.

ExileData is an independent community project and is not affiliated with or endorsed by Grinding Gear Games.
