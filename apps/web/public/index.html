Path of Exile 1 & 2

Game data for Path of Exile tools.

ExileData turns each game patch into a normalized, versioned dataset and serves it through an HTTP API. Your tool reads records instead of parsing game files.

A real response, shortened. meta.gameVersion names the patch that answered, so you can pin to it.

What you get

One dataset per patch

Every game patch becomes its own dataset. Ask for one with ?version=4.5.5.3 or take the latest, and each response names the patch it came from.

Both games

Path of Exile 1 and 2 are built from their own game files into separate datasets. They share one schema, so the same code reads both.

Built from the game files

Data is extracted from the game client ahead of time. Nothing is scraped from other sites, and a request never waits on a third party.

Stable fields, raw fields

Fields ExileData guarantees sit at the top of each record. Everything else from the game files stays in ext under its original name, so nothing is lost.

Per-key rate limits

Each key has its own per-minute limit. Every response says how many requests are left, and a 429 says how long to wait.

Available today

Base items for both games, from the latest patch. Items, mods, gems and skills come next.
